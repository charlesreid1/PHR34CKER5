# ZINES

The paper (and later ASCII) periodicals that carried the scene.

## The big three

### 2600: The Hacker Quarterly
- Founded 1984 by Emmanuel Goldstein (Eric Corley).
- Named for 2600 Hz.
- Still publishing. Meetings on the first Friday of every month, worldwide.
- Off The Hook — companion radio show on WBAI New York since 1988.

### Phrack
- Founded 1985 by Taran King and Knight Lightning on Metal Shop BBS.
- Distributed as text files. Numbered issues, numbered articles.
- Formative for the technical hacking scene: shellcode, exploit dev,
  buffer overflows, later kernel work.
- Issue 49 (1996), P. Aleph One, "Smashing the Stack for Fun and Profit"
  — arguably the most-cited hacker article of all time.

### TAP (Technological American Party / Technological Assistance Program)
- 1971–1984.
- Started as an Abbie Hoffman / Yippie project (originally called YIPL,
  Youth International Party Line).
- Mimeographed newsletter. Phreaking-first, before "hacker" was the word.
- Numbers, schematics, editorials.

## Adjacent
- **NIA** (Network Information Access), **LOD/H Technical Journal**,
  **cDc** (Cult of the Dead Cow) text files.
- Anarchist Cookbook — culturally adjacent, technically unreliable.
